艾宾浩斯单词记忆系统
基于改良艾宾浩斯遗忘曲线的 Windows 离线单词记忆工具，纯 C 语言编写，本地加密存储，自适应记忆算法，UTF-8 中文无乱码。
一、项目介绍
本工具是一款本地离线、轻量高效、数据安全的单词学习软件，采用自适应记忆算法，根据你的学习情况自动调整复习间隔，达到最佳记忆效果。
支持多词库、备份恢复、错词复习、学习统计、模拟时间等完整功能，适合个人长期背单词使用。
二、核心功能
1. 智能记忆算法
7 级记忆等级，从短期记忆到长期记忆逐步巩固
动态计算遗忘概率，优先复习最容易忘记的单词
自适应 gain/loss 学习系数，越用越贴合你的记忆习惯
自动计算复习时间，到期提醒复习
2. 单词学习
两种模式：英译中 / 中译英
错词自动收录，支持错词专项复习
待复习排行榜，按遗忘风险排序
支持单词添加、编辑、删除、搜索、浏览
3. 词库管理
支持新建 / 切换 / 备份 / 恢复多词库
词库文件加密存储
支持中文词库名，UTF-8 完美显示
自动备份 + 手动备份
4. 学习统计
连续学习天数记录
近 7 天复习量可视化图表
每日正确率趋势
自动生成学习日志
学习参数实时展示
5. 高级功能
模拟时间模式（沙盒隔离，不影响真实数据）
自定义每日学习目标
可开关 “每日必须添加新词” 限制
数据校验，防止文件损坏
三、运行环境
系统：Windows 10 / 11
编码：UTF-8（中文不乱码）
环境：无需安装任何运行库
编译：C 语言编译器（Dev-C++、VS、MinGW 均可）

七、常见问题
1. 中文乱码？
程序已自动设置 UTF-8，Windows 正常环境不会乱码。
2. 词库损坏？
使用 切换词库 → 恢复备份 即可找回。
3. 模拟时间会影响真实数据吗？
不会，模拟模式独立沙盒，退出自动清理。
4. 如何重置所有数据？
删除 .dat 和 .log 文件，重启程序即可。
