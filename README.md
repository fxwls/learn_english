艾宾浩斯单词记忆系统 README

📚 艾宾浩斯单词记忆系统
基于 改良版艾宾浩斯遗忘曲线 打造的本地离线单词记忆工具，纯C语言+Windows API开发，轻量、安全、高效，适配个人长期单词背诵需求 ✨

---
🎯 项目核心亮点
- 🔒 本地安全加密：二进制异或加密+校验和，数据全程本地存储，不上传、不泄露，隐私有保障
- 🧠 自适应记忆算法：7级记忆等级，动态计算遗忘概率，优先复习高风险单词，越用越贴合个人记忆节奏
- 💻 轻量化无依赖：纯原生C语言编写，无需额外运行库，老旧Windows电脑也能流畅运行
- 🌐 UTF-8全兼容：中文词库名、中文释义无乱码，完美适配中文用户使用习惯
- 📊 完整数据统计：连续学习天数、正确率趋势、复习量可视化，学习进度一目了然
- 🔧 丰富拓展功能：多词库管理、错词专项复习、模拟时间沙盒、自动备份，满足多样化需求

---
🚀 核心功能模块
📝 单词学习与复习
- 双模式刷题：「英译中」「中译英」自由切换
- 错词自动收纳，支持专项集中复习，精准攻克薄弱点
- 7级记忆等级体系，从短期记忆到长期记忆逐步巩固
- 复习排行功能，按遗忘风险排序，优先复习易忘单词
📂 词库管理
- 支持「新建/切换/备份/恢复」多词库，一人多库、多人共用更灵活
- 单词「增/删/改/查/搜」全功能，支持全库浏览，操作便捷
- 词库文件加密存储，自带校验和，防止文件篡改、损坏
- 自动备份+手动备份双重保障，数据永不丢失
📈 学习统计与日志
- 连续学习天数记录，助力养成每日学习习惯
- 近7天复习量柱状可视化、每日正确率趋势图表
- 自动生成独立学习日志，记录每一次学习轨迹
- 自适应参数可视化，直观查看记忆增长/衰减系数
⚙️ 高级拓展
- 模拟时间模式：沙盒隔离，测试算法不污染真实学习数据
- 自定义每日学习目标，按需设置学习强度
- 每日新词强制打卡开关，灵活适配不同学习节奏
- 数据校验、文件损坏检测机制，异常情况自动提示

📂 项目文件结构
├── main.c              // 程序入口、主菜单逻辑（核心入口）
├── vocab_core.c/h      // 全局结构体、常量、全局变量定义（核心配置）
├── ui_utils.c/h        // 控制台颜色、清屏、安全输入、字符串处理（界面工具）
├── time_utils.c/h      // 时间转换、模拟时间、日期计算（时间工具）
├── file_io.c/h         // 文件读写、加密解密、备份恢复、词库操作（文件操作）
├── review_engine.c/h   // 复习核心、答题逻辑、复习排行（复习引擎）
├── memory_algorithm.c/h// 艾宾浩斯记忆算法、遗忘概率计算（算法核心）
├── word_manager.c/h    // 增删改查单词、单词校验（单词管理）
└── statistics.c/h      // 学习统计、日志生成、参数设置（统计模块）

---
🔧 编译 & 运行步骤
1. 将所有 .c 和 .h 文件放入同一文件夹，确保无缺失
2. 打开C语言编译器（Dev-C++/VS/MinGW），导入所有文件并全员编译
3. 编译完成后，生成 .exe 文件，双击即可运行
4. 首次运行自动生成默认空词库 vocab.dat，直接开始使用

🖱️ 操作指南
主菜单功能（一目了然）
[1]添加单词   [2]开始复习   [3]浏览单词   [4]搜索单词
[5]复习排行   [6]错词复习   [7]学习统计   [8]切换词库
[9]编辑单词  [10]删除单词  [11]高级设置  [12]保存退出
基础使用流程
1. 首次使用 → 选择「1.添加单词」录入词汇
2. 日常学习 → 选择「2.开始复习」完成每日打卡
3. 数据保障 → 定期在「11.高级设置」执行手动备份
4. 多词库使用 → 选择「8.切换词库」新建独立词库
特殊指令
- 复习过程中输入 q，可快速退出当前复习界面
- 所有输入均做容错处理，非法输入不会导致程序崩溃
- 关闭程序时自动保存+备份，学习数据不丢失
