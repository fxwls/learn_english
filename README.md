# 艾宾浩斯单词记忆系统 README

# 艾宾浩斯单词记忆系统

## 项目介绍
本项目是基于 **C语言 + Windows API** 开发的本地离线单词记忆工具，依托改良版艾宾浩斯遗忘曲线算法，实现智能间隔复习、记忆强度自适应调节。
全程本地加密存储、无联网、无广告、数据安全，完美适配 Windows 平台，全局 UTF-8 编码，中文无乱码。

## 核心功能
1. 智能记忆复习
- 7级记忆等级体系，分层巩固记忆
- 动态计算遗忘概率，优先复习高遗忘风险单词
- 自适应稳定性算法，根据对错自动调节复习间隔
- 双模式刷题：英译中 / 中译英
- 错词单独收纳，支持专项错题复习

2. 完整词库管理
- 新建词库、切换多词库、备份/恢复词库
- 单词新增、编辑、删除、搜索、全库浏览
- 词库文件加密存储，自带校验和防损坏
- 支持中文自定义词库名，UTF-8 编码兼容

3. 学习数据统计
- 连续学习天数记录
- 近7天复习量柱状可视化
- 每日正确率趋势图表
- 自动生成独立学习日志
- 自适应参数可视化（记忆增长/衰减系数）

4. 拓展高级功能
- 模拟时间模式（沙盒隔离，不污染真实数据）
- 自定义每日学习目标
- 每日新词强制打卡开关
- 手动一键备份 + 程序自动备份
- 数据校验、文件损坏检测机制

## 运行环境
- 操作系统：Windows 10 / Windows 11
- 编码格式：全局 UTF-8
- 运行依赖：纯原生C + Windows API，无需额外库
- 编译工具：Dev-C++、Visual Studio、MinGW 均可直接编译

## 项目文件结构
```
├── main.c              // 程序入口、主菜单逻辑
├── vocab_core.c/h      // 全局结构体、常量、全局变量定义
├── ui_utils.c/h        // 控制台颜色、清屏、安全输入、字符串处理
├── time_utils.c/h      // 时间转换、模拟时间、日期计算
├── file_io.c/h         // 文件读写、加密解密、备份恢复、词库操作
├── review_engine.c/h   // 复习核心、答题逻辑、复习排行
├── memory_algorithm.c/h// 艾宾浩斯记忆算法、遗忘概率计算
├── word_manager.c/h    // 增删改查单词、单词校验
└── statistics.c/h      // 学习统计、日志生成、参数设置
```

## 编译&运行方式
1. 将全部 `.c` + `.h` 文件放在同一目录
2. 使用C语言编译器直接全员编译
3. 编译完成双击 exe 即可运行
4. 首次运行自动生成默认空词库 `vocab.dat`

## 操作说明
### 主菜单功能
```
[1]添加单词   [2]开始复习   [3]浏览单词   [4]搜索单词
[5]复习排行   [6]错词复习   [7]学习统计   [8]切换词库
[9]编辑单词  [10]删除单词  [11]高级设置  [12]保存退出
```

### 基础使用流程
1. 首次使用选择 `1.添加单词` 录入词汇
2. 录入完成后选择 `2.开始复习` 日常打卡
3. 定期在 `11.高级设置` 执行手动备份
4. 多人群学可使用 `8.切换词库` 新建独立词库

### 特殊指令
- 复习过程输入 `q` 可退出当前复习
- 所有输入做容错处理，非法输入不会崩溃
- 关闭程序自动保存+备份，数据不丢失

## 数据文件说明
- `xxx.dat`：主加密词库文件
- `xxx_backup.dat`：自动/手动备份词库
- `xxx_mock.dat`：模拟时间专属临时文件（退出自动删除）
- `daily_review_xxx.log`：每日学习统计日志

## 特色亮点
✅ 全局UTF-8，中文文件名、中文释义完全不乱码
✅ 二进制异或加密+校验和，防止文件篡改、损坏
✅ 模拟时间沙盒机制，测试算法不影响正式数据
✅ 静态变量优化，杜绝栈溢出、程序崩溃
✅ 完善容错：空输入、非法文件、异常数据全部兼容

## 常见问题
1. 中文乱码？
> 程序内置自动切换 UTF-8 代码，Windows 标准环境直接正常显示。

2. 词库文件损坏？
> 程序自带校验和检测，损坏会提示，可通过备份文件恢复。

3. 模拟时间会改我的真实数据吗？
> 不会，模拟模式独立生成 `_mock` 临时文件，退出自动清理。

4. 如何找回丢失词库？
> 切换词库 → 恢复备份，选择历史备份文件一键还原。
